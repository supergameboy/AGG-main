# 2026-07-28 工作日志

## 2DRPG 实时地图 — 决策效果测试页面

### 完成内容
在 `experiment-sandbox/2drpg-realtime-map/` 下创建了 `index.html` — 一个完整的决策验证测试页面。

### 功能覆盖

**左侧控制面板** (6 个模块 + 附录E)：
- 模块1: 数据模型参数 (CHUNK_SIZE, SUB_CHUNK_SIZE, LRU 容量等)
- 模块2: LLM 生成与调度 (ATL/JSON 格式切换, 边界策略A/B, P1方向阈值, P3空闲阈值, 最大并发生成)
- 模块3: 移动碰撞流式加载 (移动速度, 视野半径, 缓冲区, 碰撞开关)
- 模块4: 结果池与预判触发 (过期时间, 叙事预判, 隐藏事件密度, 池状态)
- 模块5: 前端渲染与区域切换 (渲染器类型, 等距渲染, 边界美化, 迷雾效果, 横幅测试)
- 模块6: 建筑物与内部结构 (方案A/B切换, 放置密度, LLM建筑生成器方案对比)
- 附录E: LLM建筑生成器 & 区块大小评估 (方案A/B/C对比测试, CHUNK_SIZE 64/96/128 对比)

**中间画布** (Canvas 2D):
- 1000×1000 大地图，含 15 种瓦片类型（对齐模块1 TileType 属性表）
- 程序化地形生成（种子可复现） + 区块惰性加载
- 玩家移动 (WASD) + A*寻路 (鼠标点击) + 碰撞检测
- 8种建筑物模板 (矩形/L/T/U形) 自动放置
- 实体 (NPC/敌人) 渲染
- 视野迷雾效果
- 区块网格线 + 坐标标签

**右侧监控面板**:
- FPS 实时显示
- 区块状态网格 (5×5, 以玩家为中心)
- P0-P3 预生成调度计数
- map_pool/narrative_pool 状态
- 流式加载/缓存命中率
- 瓦片图例

**底部日志面板**: 带分类的实时事件流

### 关键决策分叉可视化
- 边界策略对比 (硬边界 vs 邻居上下文): 策略B在区块边界优先匹配邻居地形
- 建筑内部方案 (A 独立地图 vs B Z轴分层): 进入/退出流程完整实现
- 区块大小评估: 切换 64/96/128 时动态更新 token 估算和生成时间
- 预生成调度 (P0-P3): 跨区块时自动触发，优先级队列模拟异步生成

### 技术要点
- 单文件 HTML/CSS/JS，零外部依赖
- Canvas 2D 渲染，视口跟随玩家
- 惰性区块生成 + 程序化地形 (简易噪声函数，种子可复现)
- 完整碰撞检测 + A*寻路
- 所有参数可通过 UI 实时调整，无需刷新
