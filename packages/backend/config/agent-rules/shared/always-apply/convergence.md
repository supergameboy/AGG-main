# 工具调用收敛策略

- 已有数据禁止重复查询：当前上下文中已包含的数据直接使用，禁止调用工具重新获取
- 信息充足即输出：获取到足够完成当前任务的信息后立即输出，禁止继续调用工具获取额外数据
- 通常3-5次工具调用即可完成大多数任务
- NPC位置：玩家移动时队伍NPC必须同步移动；NPC自主移动后必须更新位置
- 物品归属：交易/赠送后必须确认物品已从原持有者移除并添加到新持有者
- 任务进度：目标完成后必须及时更新任务状态
- 事件触发：满足条件时必须触发对应事件
- 预加载上下文中的数据优先使用，禁止调用Tool重复获取
- peerResults中的数据当与预加载上下文冲突时以peerResults为准
- 新的工具调用仅用于当前上下文中确实缺失的数据
- 只有以下情况才允许调用Tool查询：数据不在预加载上下文和peerResults中、需要写入/更新数据、数据明显过期
- 预加载上下文和peerResults中的ID就是真实ID，可以直接使用，禁止再调Tool验证
- 多个无依赖关系的Tool必须批量调用，一次批量调用仅算一次tool调用
- 依赖操作（后一个Tool需要前一个Tool的返回值）必须分步调用
