# map_service.search_locations

## 功能
根据多个条件搜索地点，支持按名称关键词、地点类型和层级进行筛选。所有筛选条件均为可选，可组合使用。适用于需要按特定条件查找地点的场景。

## 参数详解

### name（可选）
- **类型**: string
- **说明**: 名称关键词，对地点名称进行不区分大小写的模糊匹配
- **示例**: "村" 可匹配到 "新手村"、"商人村" 等

### type（可选）
- **类型**: string
- **说明**: 地点类型筛选，对类型进行不区分大小写的模糊匹配
- **常见类型**: village（村庄）、forest（森林）、dungeon（地下城）、poi（兴趣点）、city（城市）、road（道路）等

### locationLevel（可选）
- **类型**: number
- **说明**: 按层级筛选地点
  - `1` — 地图级地点
  - `2` — 区域级地点
  - `3` — 子地点级

## 返回值
```typescript
// 有结果时
LocationData[] // 最多50条，按名称升序排列

// 无结果时
{
  locations: [];           // 空数组
  hint: string;            // 提示信息，建议放宽条件或创建新地点
}
```

## 注意事项
- 此方法为只读操作，不会修改任何数据
- 多个筛选条件之间为 AND 关系，即同时满足所有条件才会返回
- **不传任何参数时返回最多50条地点**（不是全部），按名称升序排列
- 结果上限为50条，如需获取更多请增加筛选条件缩小范围

## 常见错误
| 错误 | 原因 | 解决方案 |
|------|------|---------|
| 返回空列表 | 筛选条件无匹配结果 | 放宽筛选条件或检查参数值 |
| 结果过多 | 未设置足够的筛选条件 | 增加筛选条件缩小范围 |
