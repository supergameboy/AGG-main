# map_service.get_discovered_locations

## 功能
查询当前存档下所有已发现地点的 ID 列表。此方法为只读操作，供前端小地图过滤显示——只有已发现的地点才会在小地图上显示。

## 数据来源
- `discovered_locations` 表中该存档的所有记录
- 记录由 `mark_discovered` 方法写入（探索/创建/访问/手动标记）

## 参数详解
此方法无需任何参数（saveId 从上下文自动获取）。

## 返回值

```typescript
ID[]  // 已发现地点的ID列表，如 ["loc_xxx1", "loc_xxx2", "loc_xxx3"]
```

## 注意事项
- 此方法为**只读操作**，不会修改任何数据
- 返回的 ID 列表可用于前端小地图渲染过滤
- 如果存档未开始初始化或未探索任何地点，返回空数组 `[]`
- 已发现状态是持久的：一旦标记为已发现，地点会一直保持已发现状态

## 常见错误
| 错误 | 原因 | 解决方案 |
|------|------|---------|
| 无 | 此方法为只读查询，通常不会出错 | — |
