# challenge_service.roll_dice

## 功能
解析骰子表达式（NdM[+/-K] 格式）并生成随机数。专为叙事战斗设计，让 GM 在不依赖严格数值系统的前提下做出随机判定（如命中检定、伤害波动、随机事件）。

此方法为**纯计算**，不修改任何战斗状态，不写入 StagingPool。

## 参数详解

### dice (required)
骰子表达式，格式为 `NdM[+/-K]`，其中：
- `N` = 骰子数量（1-100）
- `M` = 骰子面数（2-1000）
- `K` = 修正值（可选，正负整数）

合法示例：
| 表达式 | 含义 |
|--------|------|
| `1d20` | 投 1 个 20 面骰 |
| `3d6+2` | 投 3 个 6 面骰，结果加 2 |
| `2d8-1` | 投 2 个 8 面骰，结果减 1 |
| `4d100` | 投 4 个 100 面骰 |

### reason (optional)
投骰原因，记录到日志便于追溯。例如：
- `"命中检定"`
- `"伤害判定"`
- `"随机遭遇判定"`

## 返回值
```typescript
{
  success: boolean;       // 操作是否成功
  data?: {                // 成功时返回
    dice: string;         // 原始骰子表达式
    rolls: number[];      // 每个骰子的点数（数组长度=N）
    total: number;        // 总和（含修正值）
    modifier: number;    // 修正值（+N 或 -N，无修正时为 0）
    reason: string;       // 投骰原因（与入参一致，未传时为空字符串）
  };
  error?: string;         // 失败时返回错误信息
}
```

## 注意事项
- **纯计算方法**：不修改战斗状态，不写入 StagingPool，不触发任何副作用
- 骰子数量范围：1-100（超出报错）
- 骰子面数范围：2-1000（超出报错）
- 修正值可为正、负或零
- 随机数生成使用 `Math.floor(Math.random() * sides) + 1`，每个骰子点数为 1 到 M 之间的整数

## 常见错误

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| 骰子格式无效: xxx | 表达式不匹配 `^(\d+)d(\d+)([+-]\d+)?$` | 检查格式，确保为 `NdM` 或 `NdM+K` 或 `NdM-K` |
| 骰子数量超出范围(1-100): N | N 小于 1 或大于 100 | 调整骰子数量到合法范围 |
| 骰子面数超出范围(2-1000): M | M 小于 2 或大于 1000 | 调整骰子面数到合法范围 |
