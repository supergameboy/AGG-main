# game_time_service.get_time_greeting

## 功能
获取基于当前游戏时间的诗意问候语。不同时间段返回不同的中文诗意描述，用于 NPC 对话开场白或系统提示，增强沉浸感。

## 参数详解
无参数。

## 返回值

```typescript
{
  greeting: string;  // 基于当前时段的诗意问候语
}
```

**各时段问候语对照**:

| 时段 | 问候语 |
|------|--------|
| `dawn`（黎明） | 黎明时分，天边泛起了鱼肚白。 |
| `morning`（上午） | 早晨的阳光洒在大地上，新的一天开始了。 |
| `noon`（中午） | 正午时分，阳光正烈。 |
| `afternoon`（下午） | 午后时光，阳光变得柔和起来。 |
| `evening`（傍晚） | 黄昏降临，夕阳染红了天空。 |
| `night`（夜晚） | 夜幕低垂，星辰点点。 |
| `midnight`（午夜） | 深夜了，万籁俱寂。 |

## 注意事项
- 这是只读操作，不会修改游戏状态
- 问候语根据 `get_period_of_day` 的结果自动选择
- 适用于 NPC 对话开场白或系统消息
- 问候语内容为硬编码，不可通过配置自定义

## 常见错误
| 错误 | 原因 | 解决方案 |
|------|------|---------|
| 问候语异常 | 游戏时间未初始化 | 先调用 initialize_time 初始化 |
