# 生成模板物品池

## 任务是什么
根据模板的世界观和角色创建选项，通过LLM批量生成适合的物品并写入模板物品池。支持多轮生成，每轮生成一批不重复的物品。

## 为什么有这个任务
模板物品池为游戏初始化提供预构建物品，减少运行时LLM生成开销。编辑器中需要一键生成适合当前模板世界观的物品。

## 完成的标准是什么
1. 已生成 15-25 个物品
2. 物品覆盖武器/防具/消耗品/材料/饰品等分类
3. 物品适合模板的世界观和职业体系
4. 所有物品已通过 add_pool_items 写入模板物品池
5. 不与已有物品（包括手动添加和之前轮次生成的）重复

## 怎么完成任务

### 调用什么工具完成什么操作
1. 上下文中已预注入已有物品池数据和统计信息，直接参考即可，无需额外查询
2. 根据上下文中的模板世界观、已有物品和指定分类，调用 `template_pool_service.add_pool_items({ items: [...] })` — 批量添加新物品

### 物品生成要求

#### 根据推荐职业调整生成策略
- 如果上下文中指定了推荐职业，则**优先且主要**生成该职业专属物品，该职业物品占比不低于 70%
- 如果未指定推荐职业，则按全职业通用策略生成

#### 全职业通用策略（无推荐职业时）
- 武器（4-6个）：覆盖各职业主武器
- 防具（4-6个）：覆盖各装备槽位
- 消耗品（3-5个）：药水、食物等
- 材料（2-3个）：基础制作材料
- 饰品（2-3个）：戒指、项链等

#### 职业定向策略（有推荐职业时）
以牧师为例，当推荐职业为牧师时：
- 法杖/圣物（3-4个）：祈福权杖、圣光之杖、神圣典籍、信仰符印
- 布甲/祭袍（3-4个）：祈祷长袍、祝福头巾、虔诚护肩、圣者之靴
- 圣徽/饰品（2-3个）：光明圣徽、治愈指环、信仰项链
- 消耗品（2-3个）：圣水、祝福卷轴、净化熏香
- 材料（1-2个）：神圣精华、圣光碎片

其他职业同理：战士侧重剑盾/重甲/战利品；法师侧重法杖/法袍/魔法素材；盗贼侧重匕首/皮甲/毒药/开锁工具

- 每个物品设置 recommendedClasses 指定推荐职业（与上下文中的推荐职业一致）

### 继续生成时的注意事项
- 读取已有物品列表后，新物品名称和概念不可重复
- 继续生成时聚焦之前未覆盖的分类或品质
- 参考已有物品的数值范围，保持数值平衡
- 如果上下文不足以继续生成高质量内容，返回已完成的内容即可
