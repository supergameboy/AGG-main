# 生成模板技能池

## 任务是什么
根据模板的世界观和角色创建选项，通过LLM批量生成适合的技能并写入模板技能池。支持多轮生成，每轮生成一批不重复的技能。

## 为什么有这个任务
模板技能池为游戏初始化提供预构建技能，减少运行时LLM生成开销。编辑器中需要一键生成适合当前模板世界观的技能。

## 完成的标准是什么
1. 已生成 8-12 个技能
2. 技能覆盖攻击/防御/治疗/辅助等分类
3. 技能适合模板的世界观和职业体系
4. 所有技能已通过 add_pool_skills 写入模板技能池
5. 不与已有技能（包括手动添加和之前轮次生成的）重复

## 怎么完成任务

### 调用什么工具完成什么操作
1. 上下文中已预注入已有技能池数据和统计信息，直接参考即可，无需额外查询
2. 根据上下文中的模板世界观、已有技能和指定分类，调用 `template_pool_service.add_pool_skills({ skills: [...] })` — 批量添加新技能

### 技能生成要求

#### 根据推荐职业调整生成策略
- 如果上下文中指定了推荐职业，则**优先且主要**生成该职业专属技能，该职业技能占比不低于 70%
- 如果未指定推荐职业，则按全职业通用策略生成

#### 全职业通用策略（无推荐职业时）
- 攻击类（3-4个）：覆盖物理和元素攻击
- 防御类（1-2个）：护盾、减伤
- 治疗类（1-2个）：单体和群体治疗
- 辅助类（2-3个）：增益、减益、控制
- 被动类（1-2个）：永久生效的被动技能

#### 职业定向策略（有推荐职业时）
以牧师为例，当推荐职业为牧师时：
- 治疗类（3-4个）：单体治疗、群体治疗、持续恢复、紧急救治
- 神圣攻击类（2-3个）：圣光打击、驱散亡灵、神圣惩戒
- 增益类（2-3个）：护盾祝福、属性提升、抗性加持
- 减益/控制类（1-2个）：虚弱诅咒、恐惧
- 被动类（1-2个）：信仰之力、神圣庇护

其他职业同理：战士侧重物理攻击/防御/战吼；法师侧重元素攻击/范围控制/法术增幅；盗贼侧重暗杀/潜行/毒药/控制

- 每个技能设置 recommendedClasses 指定推荐职业（与上下文中的推荐职业一致）

### 继续生成时的注意事项
- 读取已有技能列表后，新技能名称和概念不可重复
- 继续生成时聚焦之前未覆盖的分类或职业
- 参考已有技能的数值范围，保持数值平衡
- 如果上下文不足以继续生成高质量内容，返回已完成的内容即可

### 怎么判断任务完成
```json
{
  "completed": true,
  "summary": "技能池生成完成",
  "data": {
    "generatedCount": 10,
    "categories": { "attack": 3, "defense": 2, "healing": 2, "buff": 2, "passive": 1 }
  }
}
```

### 技能 cost 类型约定
- 主动技能消耗法力值：`cost: [{ type: "mp", amount: 数值 }]`
- 消耗生命值：`cost: [{ type: "hp", amount: 数值 }]`
- 消耗体力：`cost: [{ type: "stamina", amount: 数值 }]`
- **禁止使用 `currency` 类型**（金币不是技能消耗）
- 被动技能 cost 为空数组 `[]`
- 法力消耗范围：基础技能 5-15，中级技能 15-30，高级技能 30-60
